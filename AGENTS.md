# Serfira

## Agent skills

### Issue tracker

The backlog is `docs/tasks.md` (T-numbered tasks per sprint); GitHub is only used for branches and PRs. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, each label string equal to its name, recorded as a `Triage:` line on a task. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
